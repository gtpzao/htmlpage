# Saboreio landing page

This repository deploys the Apple-inspired sales page as a static Vercel site. The production root rewrites to `apple.html`; screenshots are included in the repository under `assets/system-screens/`.

Run the carousel behavior checks with Node.js:

```bash
node --test tests/apple-carousel.test.mjs
```

No build command or environment variables are required. The commercial contact section remains a placeholder until the official Saboreio channel is confirmed.
